# Challenge - Domain Events

Aplicar o conceito de Domain Events na prática.

## Requisitos

- Implementar o evento `CustomerCreated` com dois handlers de log.
- Implementar o evento `CustomerAddressChanged` com um handler de log contendo dados do cliente.

## Como rodar os testes

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Execute os testes:
   ```bash
   npm test
   ```
